# 上下文压缩保留优先级

> 本文件为 unscoped rule（无 paths frontmatter），在每次 autoCompact 后自动从磁盘重新注入。

## 保留优先级（从高到低）

1. **当前 dispatch 的任务描述和验收标准** — 完整保留，不得摘要
2. **最新评审得分和 P0 问题列表** — P0 问题描述必须完整，不得省略
3. **设计文档摘要** — 关键决策和接口定义
4. **历史 dispatch 摘要** — 每个角色 500 字摘要

## 优先丢弃

- 中间调试过程（多次试错、调试输出、工具调用详情）
- 已关闭的阻塞项详情（只保留"已解决"标记）
- Agent 子会话的完整对话和工具调用记录（只保留摘要）
- 超过 1 个 dispatch 前的中间产物详情

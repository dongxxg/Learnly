# Debate 评分系统

> Debate 专用的对抗评分和裁决流程

## 评分计算

### 论据有效性判定

### Defender 论据 (防守方)

**有效论据标准：**
- [ ] 直接响应争议主题
- [ ] 有具体证据或逻辑支撑
- [ ] 没有回避关键问题
- [ ] 没有诉诸情绪

**评分：**
- 完全有效：+3 分
- 部分有效：+1 分
- 无效：0 分

### Attacker 论据 (攻击方)

**有效反驳标准：**
- [ ] 直接针对 Defender 论据
- [ ] 有具体缺陷证据
- [ ] 没有人身攻击
- [ ] 没有偷换概念

**评分：**
- 完全有效：+3 分
- 部分有效：+1 分
- 无效：0 分

## 致命缺陷清单

### 什么构成致命缺陷？

1. **逻辑缺陷**
   - 自相矛盾
   - 循环论证
   - 诉诸权威

2. **事实缺陷**
   - 与已知事实不符
   - 缺乏证据支持
   - 引用错误

3. **安全缺陷**
   - 忽略安全风险
   - 错误的假设
   - 不完整的边界条件

4. **实现缺陷**
   - 技术不可行
   - 成本过高
   - 维护困难

### 致命缺陷影响

- 单个致命缺陷：-10 分
- 多个致命缺陷：累积扣分

## 最终评分计算

```
Debate Score = (Defender 总分 - Attacker 总分) + 基础分

基础分 = 当前 Reviewer 得分

示例：
- 基础分（Reviewer）：75 分
- Defender 有效论据：6 分
- Attacker 有效反驳：3 分
- 致命缺陷：-10 分
- 最终得分：75 + 6 - 3 - 10 = 68 分
```

## 裁决标准

| 分数范围 | 裁决 | 行动 |
|----------|------|------|
| ≥ 80 | 通过 | 进入 archive |
| 75-79 | 有条件通过 | 进入 archive |
| < 75 | 不通过 | 返回 rework |

```markdown

### 当前质量得分
[Reviewer 得分]

### Defender 论据（防守方）
1. [论点 1]
   - 理由：[支撑理由]
   - 证据：[具体证据]

2. [论点 2]
   - 理由：[支撑理由]
   - 证据：[具体证据]

### Attacker 论据（攻击方）

   - 证据：[反驳证据]

2. [针对论点 2 的反驳]
   - 缺陷：[指出缺陷]
   - 证据：[反驳证据]

#### 额外攻击论据

- [ ] 逻辑缺陷
- [ ] 事实缺陷
- [ ] 安全缺陷
- [ ] 实现缺陷

### 关键分歧
[总结核心分歧点]

### 裁决
- Defender 得分：X
- Attacker 得分：Y
- 致命缺陷：Z
- 最终得分：[计算结果]
- 裁决：[通过/不通过]
```

## 限时机制

- Defender: 5 分钟
- Attacker: 5 分钟
- 裁决: 3 分钟

超时处理：
- 超时自动使用已提交的论据
- 不允许补充

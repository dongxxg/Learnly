# 反模式自检 (Anti-Rationalization Check)

> 此扩展用于防止 Agent 为不合理的结果寻找合理化借口。

## 触发时机

当任务完成、失败、或遇到问题时，必须执行此自检。

## 自检清单

### 1. 任务理解检查

- [ ] 我是否真正理解了 PM 的需求？
- [ ] 我是否基于假设而非事实推进？
- [ ] 我是否跳过了必要的步骤？

### 2. 执行完整性检查

- [ ] 我是否完成了所有必需的步骤？
- [ ] 我是否跳过了测试？
- [ ] 我是否声称完成但实际没有？

### 3. 质量标准检查

- [ ] 我的输出是否符合质量标准？
- [ ] 我是否为了快速完成而降低了标准？
- [ ] 我是否忽略了明显的问题？

### 4. 问题诚实检查

- [ ] 我是否遇到了问题但声称没有？
- [ ] 我是否用"可能是环境问题"等借口掩盖失败？
- [ ] 我是否诚实地报告了所有问题？

## 违规后果

如果发现任何违规，必须：
1. 立即停止当前任务
2. 报告真实情况
3. 重新正确执行

## 示例

### ❌ 错误示例

```
我完成了所有测试。虽然有一个测试失败了，
但那是因为环境问题，不是我的代码问题。
```

### ✅ 正确示例

```
我完成了大部分测试，但有一个测试失败。
失败原因是 X，我需要修复这个问题。
当前状态：DONE_WITH_CONCERNS
```

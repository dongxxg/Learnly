# 上线合规清单（个人开发者视角）

> 2026-10-15 整理。微信类目政策动态调整，**提交时以微信后台实际要求为准**；本清单为决策参考，非法律意见。
> 结论来源：微信官方《小程序开放的服务类目》（developers.weixin.qq.com/miniprogram/product/material/）当日版本。

## 结论

个人主体**无法合规上线**"知芽"当前形态的儿童互动学习内容（识字/英语/数学），卡点在类目而非技术。

- 个人主体教育类目仅有「教育服务 → 教育信息展示」，官方明文**不支持**教育视频/课程产品等服务
- 识字书写、字母笔顺、口算练习属互动学习内容，对应的非个人主体教育类目要求办学/培训许可证等资质；语数英为学科类，"双减"后线上学科培训资质基本停发，**个体工商户也走不通**
- 工具类（计算器/信息查询）硬闯属灰色地带，有下架风险

## 渠道路径对比

| 路径 | 可行性 | 说明 |
|---|---|---|
| A. 个人主体小程序，"练习工具"定位 | ⚠ 灰色 | 建议与主品牌分开命名，隔离下架风险；过审靠运气 |
| B. 个体户/公司 + 教育资质 | ✗ | 学科类线上培训资质基本停发 |
| **C. H5 先行（推荐）** | ✓ | 备案域名即可（个人可备，非经营性教育内容通常可过）；App 备案 + iOS 个人号可发教育类；小程序后置 |
